# Biohub Challenger006 — Ensemble + Fine-tuning

Kaggle notebooks for the Biohub cell-tracking competition.

- `biohub-challenger006-ensemble.ipynb` — ensemble notebook (v4, guard-disabled)
- `biohub-finetune-detector.ipynb` — fine-tunes the UNet3D detector on 8 training movies
- `CHALLENGER006_NOTES.md` — run notes

Setup for ensemble: 4 datasets (including xiaoleilian/biohub-unet3d-weights), T4×2, internet OFF, Run All.
Setup for finetune: support pack + competition data, T4×2, internet OFF, Run All.
